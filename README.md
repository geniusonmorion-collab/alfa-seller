# Альфа Селлер

Pixel-perfect реализация лендинга по макету Figma. Десктопная версия повторяет исходный артборд 1920 px, а для экранов уже 1200 px включается адаптивная мобильная компоновка.

Сайт можно открыть сразу двойным кликом по `index.html` — стили, изображения и интерактивные элементы работают без локального сервера.

## Запуск

```bash
npm install
npm run dev
```

Vite выведет локальный адрес проекта в терминале.

## Production-сборка

```bash
npm run build
npm run preview
```

Готовые файлы создаются в каталоге `dist`.
